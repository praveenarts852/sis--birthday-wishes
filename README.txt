THEN — BIRTHDAY WEBSITE

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Put the main/cover photo at: images/main-photo.jpg
4. Put the 30 photos at:
   images/photo01.jpg
   images/photo02.jpg
   ...
   images/photo30.jpg
5. Open index.html in your browser (or use the VS Code Live Server extension).

CUSTOMIZE:
- Open script.js and edit the title/note values in the memories array.
- Open index.html to edit the birthday note and wording.
- The page is responsive for phones and computers.
- Photos are loaded locally from the images folder; they are not uploaded anywhere.

TIP:
Use landscape/portrait photos alike; the gallery crops thumbnails into squares, while the popup shows the full image.
